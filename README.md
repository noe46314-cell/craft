# RecipeForge (Minecraft 1.12.2, Forge)

Внутриигровой визуальный редактор рецептов. Все правки сохраняются в обычный скрипт CraftTweaker
`scripts/recipeforge.zs`, который можно скопировать в любую другую сборку с теми же модами
(мод RecipeForge там уже не нужен, достаточно CraftTweaker).

## Как собрать .jar (GitHub Actions)
1. Создай пустой репозиторий на GitHub и загрузи в него всё содержимое этой папки (включая скрытую `.github`).
2. Вкладка Actions → build → Run workflow (или просто сделай push).
3. Когда сборка завершится, скачай артефакт `RecipeForge-jar` — внутри .jar.
4. Положи .jar в `mods`. Нужен **CraftTweaker** (для применения скриптов).
   Если у тебя уже есть рабочий build.gradle и workflow от DreadCraft — можно взять их вместо моих.

## Использование
- Клавиша **K** (меняется в настройках управления) открывает редактор.
- Слева палитра всех предметов всех модов. Поиск по названию или ID, `@hbm` — только предметы мода hbm.
- Предмет берётся кликом или перетаскиванием в слот; ПКМ очищает слот; предмет из слота можно перетащить в другой.
- «Тип» переключает: верстак по форме, без формы, печь, станции из модов, удаление рецепта.
- «Найти текущий рецепт результата» загружает существующие рецепты предмета (повторное нажатие листает варианты). Сохранение заменит старый рецепт.
- «Мои правки» — список сохранённого; клик загружает правку, «x» удаляет.
- Сохранять могут только операторы (в одиночной игре — с включёнными читами).

## Применение изменений
Скрипты CraftTweaker читаются при запуске игры. Перезапусти игру. Если стоят ZenUtils и ZenRecipeReload,
можно выполнить `/ct reload` и `/ct jeiReload`.

## Свои станции
Файл `config/recipeforge_stations.json` создаётся при первом запуске. Добавь станцию так:
`{"name":"Мод: станция","inputs":1,"template":"mods.модид.станция.addRecipe({out}, {in1}, {p});","param":"2000"}`
Подстановки: {out}, {in1}…{in9}, {p}. Точный синтаксис смотри в документации CraftTweaker/ModTweaker для нужного мода.

## Ограничения версии 0.1.0
- Теги NBT предметов не сохраняются, ore-словарь выбирается только правкой recipeforge.json вручную (`ore:ingotIron`).
- Ячейки существующих рецептов с группой предметов загружаются первым вариантом.
- Горячей замены рецептов без ZenRecipeReload нет.
